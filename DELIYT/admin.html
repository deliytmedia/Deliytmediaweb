📖 How to edit the Knowledge Base

The Knowledge Base lives in your Google Sheet under the Knowledge_Base tab.


Columns:

  • category — Group (services, pricing, process, faq, trust)
  • topic — Short name for this entry
  • keywords — Comma-separated words that trigger this entry
  • answer — The response the agent gives when this entry matches
  • active — TRUE or FALSE (FALSE hides it from the agent)

The agent searches by keyword match. The more specific your keywords, the better the match quality.

📖 How to use Ad Prompts

Each prompt powers a unique landing page. Share the URL in your ad campaign.


Landing Page URL format:

https://yoursite.netlify.app/landing.html?p=1

Tips for good prompts:

  • Start with the ad context (e.g. "Visitor came from a WhatsApp automation ad")
  • State the goal clearly (e.g. "Book a strategy call")
  • Keep replies short: "Max 2 sentences per reply"
  • Add urgency: "Always move toward booking"
